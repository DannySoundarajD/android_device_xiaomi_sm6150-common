# Qualcomm SM6150 — Common Device Tree

## Overview

This repository contains the **shared (common) device configuration** for  
Xiaomi devices based on the **Qualcomm SM6150 (Snapdragon 732G)** platform.

This avoids duplication across multiple device trees.

---

## Supported devices

- Redmi Note 10 Pro (sweet)

---

## Contents

This tree provides:
- Common BoardConfig definitions
- Shared SELinux policies
- Common hardware services
- Audio, display, GPS, and sensor configuration
- Shared overlays
